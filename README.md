# Galaxy Morphological Classification with PyTorch

A computer vision and deep learning project designed to automatically classify distant galaxies in morphological categories (spiral, elliptical, disk, etc) using optical astronomical imagery from the Galaxy Zoo

## Tech Stack
* **Language:** Python
* **Frameworks & Libraries:** PyTorch, torchvision, NumPy, pandas, Matplotlib, scikit-learn
* **Environment:** VSCode

## Project Roadmap
- [x] Environment and repository setup
- [ ] Learning the necessary frameworks (NumPy, Pandas, Matplotlib, PyTorch, etc)
- [ ] Exploratory Data Analysis (EDA) on Galaxy Zoo metadata
- [ ] Custom PyTorch `Dataset` and `DataLoader` pipeline
- [ ] Baseline Convolutional Neural Network (CNN) built from scratch
- [ ] Fine-tuning pre-trained architectures (ResNet18) via Transfer Learning
- [ ] Model evaluation (Confusion Matrix, Precision/Recall metrics)
